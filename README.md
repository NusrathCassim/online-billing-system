
# online-billing-system


## Project Overview
Pahana Edu Billing System is a **Java EE (JSP + Servlets + MySQL)** based web application designed for managing educational billing and inventory for **Pahana Edu Institute**.  

The system supports **Admin, Staff, and Customer** roles and provides modules for:
- Customer Management  
- Item & Category Management  
- Billing  
- Reports
## Features
- User Authentication (Admin/Staff Login with Session Handling)  
- Customer Management (Add, Edit, Delete, View)  
- Item & Category Management  
- Billing System (Generate bills, view bill history)  
- Reports Module (Sales, Inventory, Customers)  
- Logout & Session Security
